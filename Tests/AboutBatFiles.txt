О bat-файлах

Тесты запускаются с помощью bat-файла (run_coverage.bat для снятия покрытия либо
start.bat для проверки вывода). Необходимо прописать путь к программе
GraphDependencies.exe в начале bat-файла.

Появится файл results.txt, в котором наглядно отражена информация о каждом тесте:
входные данные и соответствующий вывод программы. Перед каждым запуском желательно
удалять выходные файлы (outNN.txt) и results.txt.

Сначала запускаются основные тесты (test01-test67): для корректных входных данных
формируются выходные DOT-файлы, для некорректных - выводятся сообщения об ошибках.
Затем выполняются три специальных запуска для проверки аварийных ветвей (без
аргументов, несуществующий входной файл, недоступный выходной файл). Содержимое
выводов записывается в results.txt.
