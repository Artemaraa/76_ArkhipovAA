# Граф зависимостей действий

Консольная программа на C++/Qt. Читает трассу выполнения, заданную в
**постфиксной (обратной польской) записи**, строит ориентированный граф
**непосредственных** зависимостей между действиями и выводит результат в
формате **DOT** (Graphviz).

Действие зависит от другого, если использует значение переменной (или элемента
массива), которое **последним** записало предшествующее действие — модель
«только последний писатель».

## Возможности

- Разбор трассы в постфиксной записи (переменные, целые числа, операторы `+ - * /`, инкремент/декремент `++` `--`, доступ к элементам массивов).
- Построение графа зависимостей с разделением рёбер на **прямые** (точное совпадение индексов) и **общие** (индекс задан переменной — на графе пунктиром).
- Встроенная в построение графа проверка согласованности размерностей переменных (скаляр всегда без индекса, массив — всегда с индексом той же размерности).
- Сбор **всех** ошибок за один проход с понятными диагностиками.
- Вывод графа в формате DOT для визуализации в Graphviz.

## Запуск

```
GraphDependencies.exe <input.txt> <output.dot>
```

- `input.txt` — входная трасса (по одному действию на строку);
- `output.dot` — файл для результата в формате DOT.

При **любой** ошибке во входных данных выходной файл **не создаётся**, а список
ошибок печатается в консоль.

## Формат входного файла

Каждая строка — одно действие вида `цель = выражение`. Правая часть записана в
постфиксной форме, токены разделяются пробелами.

| Элемент | Запись | Пример | Значение |
|---|---|---|---|
| Переменная | `[A-Za-z][A-Za-z0-9]*`, до 255 символов | `a`, `x1` | имя переменной |
| Число | целое (тип `int`) | `5`, `-3` | константа |
| Бинарный оператор | `+` `-` `*` `/` | `a b +` | `a + b` |
| Инкремент/декремент | `++` `--` (к переменной) | `a ++` | `a` с инкрементом |
| Доступ к массиву | токен `[]`, индекс **перед** ним | `a i []` | `a[i]` |
| Многомерный массив | повтор `[]` | `a i [] j []` | `a[i][j]` (глубина ≤ 5) |

Примеры строк:

```
a = 5
b = a 1 +
c = a b *
n i [] = a
v = n i [] b +
k = a ++
```

## Пример работы

Вход:

```
a = 5
b = a 1 +
c = a b *
n i [] = a
v = n i [] b +
f = n 3 [] a -
k = a ++
privet = a k -
```

Выход (DOT):

```
digraph G {
    1 [label="a = 5"];
    2 [label="b = a 1 +"];
    3 [label="c = a b *"];
    4 [label="n i [] = a"];
    5 [label="v = n i [] b +"];
    6 [label="f = n 3 [] a -"];
    7 [label="k = a ++"];
    8 [label="privet = a k -"];
    2 -> 1;
    3 -> 1;
    3 -> 2;
    4 -> 1;
    5 -> 4;
    5 -> 2;
    6 -> 4 [style=dashed];
    6 -> 1;
    7 -> 1;
    8 -> 7;
}
```

Сплошное ребро — прямая зависимость, пунктир (`style=dashed`) — общая.
Полученный `.dot` можно отрисовать в Graphviz: `dot -Tpng output.dot -o graph.png`.

## Обрабатываемые ошибки

Программа не останавливается на первой ошибке — собирает их все за один проход.

- **Файлы и объём:** входной файл не найден / не создаётся выходной / пустой вход / более 10 000 действий.
- **Структура строки:** нет знака `=`, пустая левая или правая часть.
- **Токены:** некорректное имя переменной, имя длиннее 255 символов, неизвестный оператор, число вне диапазона `int`, нецелое число.
- **Постфиксная запись:** нехватка операндов, `++`/`--` применён не к переменной, лишние операнды в стеке, незакрытая или лишняя скобка, отсутствует индекс массива, превышена глубина вложенности индексов (> 5).
- **Размерности переменных:** массив использован без индекса, скаляр использован с индексом, изменилась размерность массива.

## Сборка

Требования: **Qt 6.9.2**, компилятор **MinGW 64-bit**, система сборки **qmake**.

В Qt Creator:

1. Открыть `GraphDependencies/GraphDependencies.pro`.
2. Выбрать комплект `Desktop Qt 6.9.2 MinGW 64-bit` (для сдачи — конфигурация **Release**).
3. Собрать. Готовый `GraphDependencies.exe` появится в каталоге сборки.

Из консоли Qt (MinGW):

```
qmake
mingw32-make
```

## Тесты

Модульные тесты на **QtTest** (~115 проверок) лежат в `DependencyGraphTests/`.
Чтобы прогнать: открыть `DependencyGraphTests/DependencyGraphTests.pro` в Qt
Creator, собрать и запустить. Тестовый проект подключает исходники основного
проекта напрямую.

Покрываются: разбор выражений и действий, сравнение индексов, определение
зависимости, применение одного действия (`applyAction`) и построение всего графа
(`buildGraph`), включая проверку размерностей.

## Структура проекта

```
GraphDependencies/            основной проект
  main.cpp                    точка входа, разбор аргументов, запись DOT
  functions.cpp/.h            свободные функции разбора трассы
  dependencygraph.cpp/.h      класс DependencyGraph (построение графа, проверки)
  action.cpp/.h               действие (вершина графа)
  exprnode.cpp/.h             узел дерева выражения
  dependencyedge.cpp/.h       ребро зависимости
  error.cpp/.h                типы и описания ошибок

DependencyGraphTests/         модульные тесты (QtTest)
```

## Запуск без установленного Qt

Чтобы `GraphDependencies.exe` работал на машине без Qt, рядом с ним должны лежать
библиотеки. Проще всего — утилитой `windeployqt`:

```
C:\Qt\6.9.2\mingw_64\bin\windeployqt.exe --compiler-runtime GraphDependencies.exe
```

Минимально необходимый набор для этой консольной программы:

- `Qt6Core.dll`
- `libgcc_s_seh-1.dll`
- `libstdc++-6.dll`
- `libwinpthread-1.dll`

(в Debug-сборке имя ядра — `Qt6Cored.dll`). Папку `translations` и платформенные
плагины можно не включать — GUI у программы нет.
